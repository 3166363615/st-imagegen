# 文生图 ImageGen — SillyTavern 扩展（NovelAI V4.5）

右下角悬浮球点开即用。把酒馆里的叙事直接画成插图，自动插入聊天。
后端使用 **NovelAI 官方 API 格式**，支持填第三方中转地址。

---

## 一、安装

### 方式 A：Git 链接装（推荐）

酒馆 → 扩展面板 🧩 → 底部「Install Extension」→ 填：

```
https://github.com/3166363615/st-imagegen
```

分支留空，点「仅为我安装」→ **Ctrl+F5 强刷**。

### 方式 B：手动解压

把 `st-imagegen` 整个文件夹放进：

```
SillyTavern/public/scripts/extensions/third-party/
```

最终结构必须是 `third-party/st-imagegen/manifest.json`，不要多套一层。然后 Ctrl+F5。

装好后右下角会出现一个**渐变圆形悬浮球**，点它就是插件面板。

---

## 二、接口协议（重要）

**本插件使用 OpenAI 兼容协议**，因为实测 dangao.iisbo.com 就是 OpenAI 格式中转：

```
POST https://dangao.iisbo.com/v1/images/generations
Authorization: Bearer <你的密钥>
{ "model": "...", "prompt": "...", "n": 1, "size": "832x1216", "response_format": "b64_json" }
```

我实测过这个站点的路径：

| 路径 | 返回 | 含义 |
| --- | --- | --- |
| `/v1/models` | 401 | ✅ 存在，只是要鉴权 |
| `/v1/images/generations` | 401 | ✅ 存在 |
| `/v1/chat/completions` | 401 | ✅ 存在 |
| `/ai/generate-image` | 404 | ❌ NovelAI 原生路径不存在 |

所以 **Base URL 填 `https://dangao.iisbo.com` 即可**，插件自动拼 `/v1/images/generations`。
填 `/developer`（文档网页）也能自动纠正为根地址。

> 密钥就用中转站后台给你的那个，**不需要 `pst-` 开头**。

## 三、拿 Token（仅官方 NovelAI 需要）

1. 登录 https://novelai.net
2. 点左下角齿轮 → **Account** → **Get Persistent API Token**
3. 复制以 `pst-` 开头的字符串

> 这是 Persistent Token，长期有效。不要用 access token（1 小时就过期）。

## 四、填写面板

| 字段 | 值 |
| --- | --- |
| Base URL | `https://image.novelai.net`（第三方中转就填它的根地址） |
| Token | 你的 `pst-...` |
| 模型 | **V4.5 Full**（成人内容必须 Full，Curated 会自我审查） |

填完点 **测连接**，显示「连接成功，订阅等级：3」就通了。

然后聊天框输入 `/img`，或点面板里的**画一张**。

### 用第三方中转

Base URL 直接填中转站给的根地址即可，例如：

```
https://your-relay.com
https://your-relay.com/nai
```

插件会自动拼成 `{Base URL}/ai/generate-image`。
如果你手上给的是完整地址（带 `/ai/generate-image`），直接粘进去也能识别，会自动去掉后缀。

## 五、两个独立接口

插件把「生成 tag」和「生成图片」拆成了两套独立配置：

| | 用途 | 配置位置 |
| --- | --- | --- |
| **① 生图接口** | 把提示词发给 NovelAI 出图 | 面板第 1 组 |
| **② Tag 生成接口** | 把叙事转成英文提示词 | 面板第 2 组 |

### 为什么要拆开

NovelAI 只负责画图，它不会理解中文叙事。而**帮你写提示词的模型可能是另一个服务**——
酒馆当前在聊天的模型可能拒绝成人内容（返回 `I'm just a language model...`），
这时候你可以给 tag 生成单独配上**不设审核的接口**，生图仍然走 NovelAI。

### Tag 生成接口两种来源

| 来源 | 说明 |
| --- | --- |
| 用酒馆当前聊天模型 | 零配置，但受该模型的内容审核限制 |
| 独立接口（OpenAI 兼容） | 单独填 URL / Key / 模型，可用 DeepSeek、中转站、本地 Ollama 等 |

独立接口填法（自动拼 `/v1/chat/completions`）：

```
Tag 接口 URL:  https://api.deepseek.com
Tag 接口 Key:  sk-...
Tag 模型:      deepseek-chat
```

填完点「测试 Tag 接口」验证。

### 重要：拒绝话术会被自动拦截

模型拒绝时会返回类似：

```
I'm just a language model and can't help with that...
```

插件会**识别这类话术并判定本次失败**，自动回退到本地中文词映射，
**绝不会把拒绝文本当作提示词送去生图**（那会画出一堆文字废图，还白扣 Anlas）。

预览词时如果看到黄色警告，说明 tag 接口拒绝了，此时：

1. 换一个不设审核的 tag 模型（推荐走独立接口）
2. 或直接把「启用 AI 生成 tag」关掉，用本地映射

## 六、图文混排（每楼多张图穿插正文）

每条 AI 回复的「⋯」菜单里有一个 ✨ 按钮。点它后会：

1. **切分**这条消息为若干段落
2. **打分挑出最值得画的段落**（排除时间戳行、纯对白、过短段落）
3. 每个选中段落 → tag 接口 → 生图接口
4. **把图直接插在那一-段后面**，形成图文混排

面板里可设「每楼图数」（默认 3）。

### 选段规则

| 会选中 | 不会选中 |
| --- | --- |
| 场景描写（窗、雨、烛光、霓虹） | `『Monday - 2050 - 5 - 4 - Tokyo』` 这类时间戳 |
| 人物外观/动作（发、眼、跪坐、颤抖） | `「……想要……」` 这类纯对白 |
| 光影/镜头（逆光、倒影、特写） | 少于 30 字的碎句 |

打分依据是画面信号词密度 + 段落长度，取分数最高的 N 段，再按原文顺序插入。

### 两种输出模式

| 模式 | 效果 |
| --- | --- |
| **穿插到正文段落**（默认） | 图片出现在段落之间，阅读连贯 |
| 追加为独立消息 | 图片作为单独一条消息，排在楼层后面 |

> 穿插模式的图片是渲染时插入 DOM 的，不写进聊天记录。刷新页面后图片会消失，重新点按钮即可。

## 七、自然语言出图（你要的重点）

**结论：V4.5 原生支持自然语言**，官方文档明确写了 *natural language understanding*。
所以不需要强行转成 tag —— 但纯长句会丢细节，纯 tag 又死板。

插件默认用**混合模式**，效果最好：

| 模式 | 说明 | 适合 |
| --- | --- | --- |
| **混合**（默认） | 先一句自然语言描述画面，再跟一串关键 tag 兜底 | 日常推荐 |
| 纯自然语言 | 只输出 2–4 句英文 cinematic 描述 | 氛围向、少约束 |
| 纯 tag | 标准 danbooru 串 | 精确控制服装/姿势 |

### ⚠️ 必须开「启用 AI 生成 tag」

NovelAI 的 T5 tokenizer **不支持中文**。如果直接把中文正文送去生图，那些字符全是噪音，
结果就是模糊色块（俗称鬼图）。插件现在会把残留中文强制剥离，但本地词表能力有限，
只能给出 `window, carpet, kneeling` 这种稀疏关键词。

**想画出丰富、贴合剧情的图，必须让模型把段落翻译成英文 tag/短句。**

### 关键：「用当前模型理解叙事」必须开

这是把中文剧情变成英文提示词的核心。勾上后，插件会把当前 AI 回复交给**你正在聊天的模型**，让它：

- 剥掉所有对白和内心独白（对话不是画面）
- 只保留可见内容：人物、身体、服装、姿势、表情、动作、场景、光线、构图
- 输出英文（V4.5 的 T5 tokenizer 不支持中文，中文塞进去等于噪音）
- 保留露骨内容，不软化

面板里有 **预览词** 按钮，出图前可以先看它到底要发什么，不满意就调。

关掉这个开关也行，走本地兜底：插件自己抽画面 + 把常见中文词（白发/红眼/少女/窗边…）映射成 danbooru tag。够用但不如 AI 润色精准。

## 八、成人向

面板「成人向」有四档，默认 **强**：

| 强度 | 注入内容 |
| --- | --- |
| 关闭 | 不加任何成人词 |
| 轻 | 暧昧向：seductive pose, half-lidded eyes, revealing clothes |
| **强**（默认） | 裸露向：explicit, uncensored, nsfw, nude, nipples, detailed anatomy, sweat… |
| 极强 | 叠加性行为词：sex, intercourse, spread legs, pussy, orgasm…，并强制排除 censored |

所有档位都会把 `child, loli, shota, underage, teen…` 写进**负向词**，强制排除。

### 三个实际要点

1. **必须用 V4.5 Full**。Curated 模型被训练成避开敏感内容，开再强的词也白搭。
2. **负向预设保持「重」**。NovelAI 的 ucPreset 会压制崩坏肢体，比手写负面词有效。
3. 如果画面还是"差一点"，按这个顺序调：
   - 成人强度提到「极强」
   - 补充要求里直接写姿势/镜头，如 `lying on bed, from above, close-up`
   - 引导（cfg）从 5 调到 6–7，让它更听话
   - 步数 28 够用，别超 50

> 提示词层面能做的就这些。模型本身的安全分类属于 NovelAI 服务端，插件不涉及绕过。

## 九、画面参数速查

| 参数 | 建议 | 说明 |
| --- | --- | --- |
| 宽 × 高 | 832×1216 | 竖图。必须是 64 的倍数 |
| 步数 | 28 | 官方推荐值，够用 |
| 引导 (cfg) | 5 | 想更贴合提示词就 6–7 |
| 采样器 | k_euler_ancestral | 通用；想干净可换 k_dpmpp_2m |
| SMEA | SMEA | 提升细节；DYN 更强但更慢 |
| 种子 | -1 | 随机。想复现就填出图后显示的那个数 |

面板出图成功会在提示里显示 `seed xxx`，填回种子栏就能复现同一张。

## 十、自动出图

| 模式 | 行为 |
| --- | --- |
| 关闭（默认） | 只能手动 `/img` |
| 每 N 条 AI 回复 | 每聊 N 轮配一张 |
| 命中关键词 | AI 回复里出现你设的词才画 |

自动模式会消耗 Anlas 和时间，间隔别太小（建议 ≥4）。

插件已做防护：**自己插入的图片消息不会再触发生成**，不会自激循环。

## 十一、常见问题

**右下角没有悬浮球**
- Ctrl+F5 强刷；还不行看 F12 控制台有没有红色报错
- 确认目录是 `third-party/st-imagegen/manifest.json`

**点画一张提示「请填写 Token」**
- Token 必须是 `pst-` 开头的 Persistent Token

**返回 401**
- Token 失效，重新生成一个

**返回 402**
- Anlas 不足。Opus 订阅在 ≤28 步、常规分辨率下免费

**返回 429**
- 请求太快，等几秒。自动出图间隔调大

**能出图但角色不像**
- 在「角色外观」里填固定 tag，如 `1girl, long silver hair, red eyes, black long coat`
- 点「记住当前角色外观」，之后切到这个角色自动套用

**画面全是日文/乱码**
- 提示词里混进了中文。V4.5 的 T5 tokenizer 不支持中文，务必开着「用当前模型理解叙事」

**图片存哪**
- 存到酒馆自己的 `data/<用户>/user/images/<角色名>/`，和原生图片一致
